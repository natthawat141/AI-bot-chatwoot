# รูปแบบ Excel/CSV สำหรับแพ็กเกจและโปรโมชัน

ระบบนำเข้าไฟล์ได้เฉพาะ **แพ็กเกจและโปรโมชัน** เท่านั้น ส่วน FAQ และคลังความรู้ให้เพิ่มหรือแก้ไขจากหน้าเว็บโดยตรง เพื่อให้ตรวจสอบเนื้อหาได้ง่ายและลดความเสี่ยงจากการนำเข้าผิดหมวด

## หลักความปลอดภัย

- ระบบตรวจไฟล์และแสดงตัวอย่างก่อน ยังไม่บันทึกทันที
- `code` เป็นรหัสประจำรายการที่ต้องกรอกและต้องไม่ซ้ำ
- ถ้า `code` มีอยู่แล้ว ระบบจะ **ข้ามและไม่เขียนทับข้อมูลเดิม**
- ก่อนบันทึกต้องกด “ยืนยันเพิ่ม” และยืนยันในกล่องเตือนอีกครั้ง
- รายการใหม่จะถูกเพิ่มเป็น **ฉบับร่าง** (`is_published = false`) AI จึงยังไม่นำไปตอบ
- เมื่อตรวจสอบข้อมูลแล้ว ให้เข้าเมนูแพ็กเกจ แก้ไขรายการ และเปิด “เผยแพร่” เพื่อให้ AI ใช้ตอบ

## รูปแบบไฟล์

- รองรับ `.xlsx`, `.xls`, `.csv` ขนาดไม่เกิน 5 MB
- Excel อ่านข้อมูลจากชีตแรก
- CSV ต้องเป็น UTF-8 และใช้ comma (`,`) คั่นค่า
- ห้ามเปลี่ยนชื่อหรือสลับคอลัมน์
- ช่องที่ไม่บังคับสามารถเว้นว่างได้
- วันที่ใช้รูปแบบ `YYYY-MM-DD`

หัวตารางต้องเรียงตามนี้:

```text
code,name_th,description_th,price,sale_price,effective_from,effective_until,terms,keywords
```

| Column | Required | Description | Example |
|---|---:|---|---|
| `code` | Yes | รหัสไม่ซ้ำ ใช้ตรวจข้อมูลซ้ำ | `PROMO-2026-001` |
| `name_th` | Yes | ชื่อแพ็กเกจหรือโปรโมชัน | `โปรโมชันดูแลผิว` |
| `description_th` | No | รายละเอียดที่ AI ใช้ประกอบคำตอบ | `บริการ 3 ขั้นตอน` |
| `price` | No | ราคาปกติ ตัวเลข ไม่ใส่ comma | `1500` |
| `sale_price` | No | ราคาโปรโมชัน | `1290` |
| `effective_from` | No | วันเริ่มใช้ | `2026-07-01` |
| `effective_until` | No | วันสิ้นสุด | `2026-12-31` |
| `terms` | No | เงื่อนไขและข้อจำกัด | `ใช้ได้ 1 ครั้งต่อคน` |
| `keywords` | No | คำค้น คั่นด้วย comma | `โปรโมชัน,ดูแลผิว` |

## ขั้นตอนนำเข้า

1. ดาวน์โหลดไฟล์ตัวอย่างหรือไฟล์เปล่าจากหน้า “นำเข้าแพ็กเกจ”
2. กรอกข้อมูลโดยไม่แก้หัวตาราง
3. เลือกไฟล์ แล้วกด “ตรวจสอบไฟล์”
4. ตรวจจำนวน เพิ่มใหม่ / รหัสซ้ำ / ข้อมูลผิด และดูรายละเอียดแต่ละแถว
5. กด “ยืนยันเพิ่ม” และยืนยันในกล่องเตือน
6. ไปหน้าแพ็กเกจ ตรวจข้อมูล แล้วเปิด “เผยแพร่” เฉพาะรายการที่พร้อมให้ AI ใช้

FAQ และคลังความรู้ไม่มีการนำเข้า Excel/CSV ให้จัดการผ่านหน้าเว็บของแต่ละเมนูเท่านั้น
